# Bookmark Extractor – Android releases

Signed APK files of the Bookmark Extractor Android app. Installed apps check this page for
updates automatically (Settings → Updates). The source code is private.

**Install:** download the newest `.apk` from the [`apk`](apk) folder (the version is in
[`latest.json`](latest.json)), open it on your phone and allow installing from this source.

Website: https://www.bookmarkextractor.uk
